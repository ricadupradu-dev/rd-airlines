🛫 Selecionar voo para SimBrief

Escolha um voo da malha RD AIRLINES e abra o SimBrief Dispatch com os dados principais do voo prontos para conferência.

O SimBrief exige uma conta SimBrief/Navigraph. A RD AIRLINES pode abrir o Dispatch do SimBrief com origem, destino, voo e aeronave já preenchidos. A geração automática via API depende de uma chave oficial do SimBrief/Navigraph.

Como usar

  1. Selecione o voo RD.
  2. Confirme a aeronave ICAO sugerida.
  3. Clique em Copiar dados para SimBrief.
  4. Use Enviar rota ao piloto IA para abrir o SimBrief já com a rota preenchida.

O SimBrief documenta que os campos mínimos para um plano são origem (orig), destino (dest) e tipo de aeronave (type). citeturn1search1
